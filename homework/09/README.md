## 各作業詳細說明

### 作業 00 — Next.js 前端 + Node.js 後端

- **前端：** Next.js 16（App Router）+ React 19 + TypeScript + Tailwind CSS
- **後端：** Node.js Express 伺服器（RESTful API）
- **位置：** `homework/00/frontend/` 與 `homework/00/backend/`

### 作業 01 — HTML 個人介紹網頁

- 使用 Flexbox 雙欄佈局（左側聯絡資訊 / 右側學歷專長）
- 響應式設計（RWD），行動裝置自動切換為單欄
- **位置：** `homework/01/aboutme.html`

### 作業 02 — HTML 表單設計

- 餐廳用餐體驗滿意度調查表
- 包含：日期選擇、下拉選單、單選評分、複選標籤雲、文字評論區
- 自訂品牌色彩與卡片式設計
- **位置：** `homework/02/2.html`

### 作業 04 — JavaScript 基礎語法練習

10 題循序漸進的 JS 練習：
1. 數值範圍判斷（if）
2. 偶數產生器（for）
3. 倒數計時器（while）
4. 溫度轉換器（function）
5. 陣列總和計算（array + for）
6. 物件資訊操作（object）
7. 尋找最大值（function + array）
8. 購物清單小計（array of objects）
9. JSON 資料解析
10. 水果清單檢查器（Array + Function + if）

- **位置：** `homework/04/`

### 作業 05 — JavaScript 回呼函式

- 高階函式接收兩個數字與一個回呼函式，分別進行加法與減法運算
- **位置：** `homework/05/`

### 作業 07 — JavaScript 物件操作

- 物件屬性存取練習（點記法與括號記法）
- **位置：** `homework/07/`

### 作業 08 — 社群平台（前後端分離）

多種後端伺服器實作 + 統一的 Next.js 前端：

| 後端 | 技術 | 位置 |
|------|------|------|
| Node.js | Express | `homework/08/server-node/` |
| Python | FastAPI | `homework/08/server-fastapi/` |
| Rust | Actix-web | `homework/08/server-rust/` |

- **前端：** Next.js 16 + React 19 + Tailwind CSS 社群平台（發文、按讚、留言）
- 支援即時切換不同後端伺服器
- **位置：** `homework/08/social-app/`

### opencode — 部落格系統

- Node.js + Express + SQLite 簡易部落格
- 支援文章發表與 CRUD 操作
- **位置：** `homework/opencode/blog/`
